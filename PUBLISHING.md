# KantaOke Release Guide

This repository hosts official KantaOke Android app updates.

Each APK is built, tested, and signed through our private development repository before it is published here.

## Release Channels

- **Stable** — Tested releases
- **Beta** — Early access updates
- **Developer** — Experimental builds

## Publishing Updates

New builds are published through GitHub Actions after approval. The release workflow handles signing, APK verification, uploading, and updating the channel information.

Once a release is published, users can find it in **KantaOke → Settings → Software Updates**.

Release notes stay simple: what changed, what was fixed, and anything users should know.
